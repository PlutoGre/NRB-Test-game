# 11 运宝与养成系统

[返回扩展指南](扩展指南索引.md)。本批将运宝、装备养成、奥义扩展、船员养成、潜能训练、船舱接入本地账号和真实战斗。六项入口位于“冒险”，永久开放，无等级门槛。Android 与 Web 共用 C++ 页面及服务端规则，本次不构建或验证 iOS。

这是采用本地默认规则的功能版本，使用现有图片及可滚动的共用操作页。参考 APK 用于确定玩法方向；本批不复刻其所有界面、商业数值或配套系统。实际验证范围见[安卓与网页验证记录](../reference/运宝与养成安卓网页验证记录.md)。

## 默认玩法与费用

费用中的“下一阶”指当前等级加一。操作均有确认步骤，钻石、贝里及道具由服务端核验和扣除。领取传书后，奖励才进入钱包或背包。

| 功能 | 默认规则 |
|---|---|
| 运宝 | 每天 3 次，每次 60 秒；普通、精良、珍稀三种品质；10 钻石刷新，10 钻石立即完成；可离线计时，到时手动领取奖励 |
| 装备淬炼 | 最多 20 级，每级花费 `1000 × 下一阶` 贝里，按装备类别增加 5 点攻击、防御或生命 |
| 装备进阶 | 最多 10 阶，花费 `20 × 下一阶` 钻石；每阶增加该装备实例对应属性的 2% |
| 装备分解 | 仅限未穿戴装备；消耗该实例，获得 10 工坊碎片，并通过传书返还 3000 贝里及本工坊投入的 80% |
| 装备合成 | 30 工坊碎片和 20000 贝里，任选雷鸣龙牙棒、海神羽织、海洋之心之一；成品通过传书发放 |
| 奥义进化 | 最多 10 阶，每阶花费 `20 × 下一阶` 钻石及 `1000 × 下一阶` 贝里；战斗数值每阶增加基础数值的 5%，保留原等级和装配关系 |
| 天生奥义替换 | 100 钻石，可替换为配置中的奥义 41、44、88；保留实例 ID、等级、进化阶数，额外奥义不能使用此功能 |
| 船员进化 | 最多 10 阶；花费 `30 × 下一阶` 钻石及 `2000 × 下一阶` 贝里，每阶增加基础四维的 3% |
| 船员超进化 | 普通进化达到 3 阶后开放，最多 5 阶；花费 `100 × 下一阶` 钻石及 `10000 × 下一阶` 贝里，每阶增加基础四维的 5% |
| 船员培养重生 | 仅重置本页的进化与超进化，返还本页累计投入的 80%，通过传书领取；原等级、突破、装备、奥义和潜能训练保留 |
| 潜能训练 | 每次消耗 5 个潜能药剂，生成一份随机预览；保留消耗 1 点剩余潜能，放弃不扣潜能、不退药剂；必须处理当前预览后才能再训练 |
| 船舱 | 梅丽号免费，桑尼号首次购买 100 钻石，之后免费切换；共 7 舱位，第一位免费，其余花费 `20 × 舱位序号` 钻石解锁 |
| 舱位升级 | 初始 1 级、最高 10 级，花费 `1000 × 下一等级` 贝里；后备船员提供 `1% × 舱位等级` 的基础四维，作用于全队 |
| 船体强化 | 每船体独立保存，初始 0 级、最高 20 级；花费 `5000 × 下一等级` 贝里，每级给全队增加生命 4、攻击 2、防御 1、意志 1 |

本批装备淬炼、装备进阶、奥义进化和船员进化均必定成功。百分比以基础实例属性计算，与原成长系统并存，重算时不会在已加成的快照上反复叠加。装备分解返还仅统计本工坊投入，不返还原强化费用。

### 运宝概率与奖励

| 品质 | 刷新概率 | 奖励 |
|---|---:|---|
| 普通 | 60% | 贝里 5000、潜能药剂 5 |
| 精良 | 30% | 贝里 10000、潜能药剂 10、钻石 5 |
| 珍稀 | 10% | 贝里 20000、潜能药剂 15、钻石 10 |

次数按北京时间每天零点重置，在开始运输时计入当天次数。运输中的品质固定，不能刷新；完成后须先领取，再开启下一次。离线不暂停计时，领取完成后品质重置为普通。服务端生成随机品质和奖励，客户端不能指定概率或数量。本批不包含抢夺、护送、排行榜及跨服匹配。

### 潜能随机结果

生命、攻击、防御、意志各 25% 概率，增量单位在 1、2、3 中等概率选择。每单位分别为生命 4、攻击 1、防御 1、意志 2。预览、累计已保留加成和接受次数保存在服务端，断线不会重新抽取同一份预览。普通训练、进化和船舱的加成分开保存。

### 船舱约束与助缘

只能安置当前账号拥有、未过期、未上阵的后备船员。同一实例只能在一个舱位；安置和移出均不消耗卡牌。住客的模板参与上阵船员的人物缘分判定，但不会直接加入出战阵列。全队加成取住客的基础生命、攻击、防御、意志，不把其装备、奥义及本批其他养成重复折算。

切换船体保留同一套舱位、住客和舱位等级，各船体的强化等级独立。旧玩法将住客上阵、出售或消耗后，在后续请求或重新登录时自动清理无效住客并重算全队属性。船舱助缘仍沿用已有的服务端缘分模板，没有另建一套卡牌关系表。

船员“超进化”在本批表示额外成长阶段，不更换角色模板或美术；“培养重生”也不是原有卡牌重置功能的替代入口。

## 更新和部署

1. 按[服务端数据备份与迁移](../服务端数据备份与迁移.md)备份当前数据库，再运行停止服务脚本。
2. 更新仓库并运行 `启动服务.cmd`。部署会编译服务端覆盖包、追加冒险表入口、安装新规则，并将默认资源版本提高到 **1.80.0**；已有更高版本继续保留。
3. 重新构建 Android 或 Web。新页面包含 C++ 原生代码，仅热更新资源不能让旧二进制获得新功能。
4. Android 安装对应 APK；Web 运行本地启动脚本并刷新页面。进入“冒险”，横向滑动查看六个新增入口。

常规克隆、打包和部署均不需要原参考 APK。部署标记为 `runtime/server/private/expansion-systems-v1.json`，重复启动不会重复追加入口。服务仍在运行时，脚本会提示更新待应用，需停止后再启动。不要混用旧客户端二进制与新资源表。

## 调整默认规则

| 文件 | 用途 |
|---|---|
| `server/config/xml/expansionSystems.json` | 新部署默认规则 |
| `runtime/server/server/xml/expansionSystems.json` | 当前已部署实例实际载入的规则 |
| `resources/catalog/expansion-systems-v1.json` | 发布入口、资源版本及默认规则的校验信息 |

自定义运行目录相应替换 `runtime/server`。停止服务后编辑实际规则，再启动载入。已存在的实例配置会保留，不会被仓库默认值覆盖；因此调整本机规则和调整新电脑默认值是两个操作。

规则按 `transport/equipment/skills/crew/training/cabin` 分组，`enabled` 控制各自入口及效果。费用、上限、概率、奖励、配方、天生奥义候选和加成向量均从该文件读取。船舱默认限制 2 船体、最多 7 舱位；扩展界面结构时需相应修改代码。

修改仓库默认规则后，应同步发布清单中 `serverFiles.expansionSystems.json.sha256`。不要修改入口 ID `9010～9015` 或类型 `92～97`。新增当前客户端没有的模板或图片还需同步资源并重新打包。配置数值、物品或数组不合法时，初始化会记录错误并拒绝完成启动。

## 数据、事务和迁移

| 数据位置 | 保存内容 |
|---|---|
| `dzm.nrb_expansion` | 每个角色一条 JSON 状态，包含六项进度、训练预览、累计投入、船体/舱位；另有版本号与更新时间 |
| `dzm.nrb_expansion_requests` | 角色和操作编号组成主键，保存已提交操作结果，处理断线和重复点击 |
| 原 `player` 表 | 实际钻石和贝里余额 |
| 原 `equip/skill/disciple/bag/battle` 表 | 原物品实例、天生奥义替换、药剂/潜能消耗和真实战斗快照 |
| 原 `rewards` 表 | 运宝、合成、分解及重生的实际奖励传书 |

扣费、扩展进度、实例变化、奖励与操作回执在同一事务提交，提交成功后再更新内存。已有战斗快照在登录及养成后由基础实例重算；原有换装、换人、升级触发的重算同样经过加成入口。完整数据库备份包含两张新表，迁移时应与账号、角色、背包和传书一起恢复。

客户端按账号、区服及玩法保存待确认操作编号。断线后“刷新 / 核对”重发原编号，服务端返回原结果，不再次扣费或发奖。旧进度版本、旧规则版本、非本人实例及非法操作会被拒绝。若数据库提交结果无法确认，当前角色会冻结保存和操作以保护权威数据；检查服务端错误日志并重启，使角色从数据库重新载入。不要在游戏服在线时直接修改角色资产或扩展 JSON。

## 正常停服

更新后的停止脚本使用当前实例专属的本机凭据通知游戏服退出，停止接收新玩法请求，等待 JVM 执行停服保存后再关闭数据库。停止窗口出现 `Game server exited after saving players.` 后才继续结束数据库；保存等待超时或停服回执异常时保留数据库，不强杀游戏服。常规停止入口不变。

首次更新仍在运行的旧覆盖包时，旧进程尚无该接口，脚本会明确提示兼容停止模式；重新启动新覆盖包后启用正常保存退出。实例凭据在部署私有配置中生成，不需要输入管理工具密码，不提交 Git。
