# 07 新版 APK 内容差异与移植清单

2026-11-03 后续已接入 All Blue 和幸运转盘的共享客户端代码、本地服务端及永久入口，使用自定义固定奖池；本批尚未编译或运行验收。范围、配置和更新方式见 [10 永久活动](10_永久活动移植与配置.md)。下文保留初始分析快照。

最适合先扩展的是基础卡牌、基础装备和沿用现有类型的被动奥义。All Blue、转盘、运宝也有可读的 Lua 页面和协议资料，可以作为后续独立玩法的实现依据。宠物、恶魔果实、船舱、跨服战等涉及新的持久化和战斗规则，不能只复制资源表或页面。

本文对比当前仓库与用户提供的 `xy1lule2eb176.apk`，并单独记录该 APK 指向的线上热更新版本。**安装与资源同步已完成，目前到达账号登录页；玩法尚未登录验证。下文的移植优先级是代码与资源分析结论。**

后续首批实施范围已确定为44张资料完整的基础卡牌、29件装备、9个被动奥义；6张缺资料的卡暂缓。代码、资源和更新步骤见 [08 首批内容移植](08_首批内容移植与更新.md)。本文的数量与模拟器状态保留审计时的快照，不作为本批的实测结论。

## 2. 模板数量必须区分 APK 和线上更新

以数字模板 ID 去重统计；本地基线是主工程的发布表和对应明文资料，不把玩家拥有数量当作模板数。

| 类别 | 本地 | APK 自带 | APK 新增 ID | 线上更新 | 线上相对本地新增 ID |
|---|---:|---:|---:|---:|---:|
| 卡牌 | 2,324 | 3,581 | 1,257 | 5,409 | 3,085 |
| 装备 | 91 | 916 | 825 | 1,949 | 1,858 |
| 奥义 | 77 | 159 | 82 | 138 | 61 |
| 缘分 | 688 | 1,029 | 341 | 1,631 | 943 |

卡牌包含进化形态、相同人物的不同模板和其他用途模板；奥义包含培养材料。不能把上表解释为新增了 1,257 名独立角色或 82 个全新战斗机制。

线上卡牌表有 5,412 行、5,409 个不同 ID：`2439`、`130026` 各有相同内容的重复行，`130027` 有内容不同的重复行。线上奥义表与 APK 的 ID 编排也不同。移植时应固定选定的数据版本，逐 ID 合并；不能混用两份清单或直接覆盖本地表。

完整新增 ID 清单采用 UTF-8 BOM，可用 Windows Excel 打开：

- APK：[卡牌](data/new-apk-3.3.0/apk-added-cards.csv)、[装备](data/new-apk-3.3.0/apk-added-equipment.csv)、[奥义](data/new-apk-3.3.0/apk-added-skills.csv)。附图片、音效等引用的包内可用性检查。

CSV 的资源可用性是对 APK 文件和图集中帧名的静态检查；`missing` 还需结合热更新及本地已有资源检查，不能单凭此值判断游戏一定显示失败。

## 5. 直接复制会遇到的兼容问题

1. **卡牌列顺序不同。** 本地 `DataTableManager.h` 的 `MAX_YUANFEN_NUM=6`，旧 `Disciples.txt` 为 24 列，新表有 30 列，包含十个缘分及新增图标字段。整表覆盖会让显示开关和图片路径错位。
2. **缘分表达式不同。** 本地 `BattleUtil.java` 按 `_` 拆分后直接转整数，新表还用 `#` 表示可选形态组合。原样导入既可能解析失败，也不能正确激活缘分。
3. **品质和派生模型不同。** 高品质卡、进阶装备与技能需要对应显示、成长和消耗，不能只按 ID 大小映射旧模板。
4. **Lua 有原生接口依赖。** 解码得到的是可读 Lua，不包含所有 C++ 单例、表管理器和战斗实现；新旧 `CommonPage`、`LuaHelper` 也需要逐接口比较。
5. **协议不等于处理器。** `_pb.lua` 能提供字段号、类型和消息结构，操作码还要与本地分发核对，并补齐 Java 业务、数据库、保存队列和客户端刷新。
6. **资源路径有层级与大小写差异。** 新包使用 `txt/`、`ccbi/`、`battleperson/` 等目录；本地大量资源在根目录。Android、iOS 与 Web 都要核对实际引用，不能依赖 Windows 不区分大小写的路径行为。

新增卡牌、装备和奥义的现有扩展位置分别见 [03 卡牌与缘分](03_卡牌与缘分.md)、[04 装备](04_装备与强化.md)、[05 奥义](05_奥义与技能.md)。独立玩法应同时接入 C++/Lua、Java、协议和资源发布，避免只修改 Android 后让 iOS/Web 缺失功能。
