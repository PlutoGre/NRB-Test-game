首页布局的后续移植见[首页界面移植说明](首页界面移植说明.md)。

本次更新以已登录参考 APK 的雷电模拟器画面，以及此前提取的 Lua、CCB 和图集为依据。参考角色已达到 15 级，保持现有阵容。本次没有启动本地游戏服，也没有构建、安装或运行改造后的客户端；仅完成参考界面采集、资源提取、代码修改和源码检查。

| 船舱 | 实机首页船只进入船舱改造页，船体居中、周围部位槽、顶部属性。实机观察的是参考版船舱改造，不是本地七后备舱位规则 | 借鉴槽位总览与属性分区；七个后备舱位可直接点选，分别显示住客、锁定及等级，再进行选人、安置、移出和强化。不增加未实现的船首/船帆养成或换肤功能 |

本次是按参考美术和交互组织本地已有玩法，并非参考版本全部画面、动画及规则的逐像素复刻。

## 界面与服务端的边界

`ExpansionSystemsPage` 继续通过 `48003/48004` 请求现有玩法。新增的 `view.presentation` 只供展示：

- `selected`：本角色所选实例、模板 ID、名称、等级和类别。图片按客户端模板表查找，不接受任意远程图片地址。
- `metrics`：服务端计算的状态、费用相关余额、等阶、训练结果等展示行。
- `previews`：按操作名分组的成长前后数值；船员为本扩展成长加成，不是包含装备的总战力。
- `seats`：七舱位解锁、等级和住客快照。锁定舱位仍可选中，安置等执行权限由服务端原规则校验。
- 原 `view.lines/actions` 保留。背包选择和配方操作附带 `subject`，供选择弹层及物品图标使用。

页签切换、弹层关闭和选中对象不扣费；执行操作沿用原有版本校验、事务和请求编号。超时仍保留原请求，点击“核对操作”重发同一编号。查看说明及操作结果时暂停运宝轮询，避免弹层被定时刷新打断。长内容按实际高度滚动，主导航保留在内容区外。

新客户端需要配套新服务端的展示快照。连到旧服务端时，显示“请先更新并重启服务端”，不会退回不完整界面继续提交养成。

## 资源与后续维护

美术位于 `resources/client/ported/growth/v1/`，文件名统一以 `nrb_growth_` 开头，避免旧引擎按文件名查图时覆盖原帧。资源在 `resources/catalog/expansion-systems-v1.json` 中登记 SHA-256，发布版本为 **1.81.0**。升级时保留部署实例自定义玩法规则。

`scripts/import_growth_ui.py` 仅用于再次从已提取 APK 导入选定资源，需要 Python 和 Pillow；普通电脑克隆仓库后构建不需要 APK、Pillow 或本机提取目录。入口保持 `9010～9015`，类型保持 `92～97`。
