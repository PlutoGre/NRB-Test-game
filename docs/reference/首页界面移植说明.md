# 首页界面移植说明

本次根据已登录参考 APK 的 15 级首页重做本地主页布局。参考截图见[参考 APK 首页](images/home-ui-reference/参考首页.png)。该图片为参考程序画面，不是更新后的本地客户端截图。

## 布局与入口

| 区域 | 本地实现 |
|---|---|
| 顶部角色栏 | 地图底纹、头像框、昵称、等级、VIP、经验条、贝里、钻石、体力与精力，读取当前登录角色信息 |
| 右上角 | 参考版圆框与图标接入本地“传书”，显示实际未读数量；参考版此处的任务系统未在本次新增 |
| 阵容栏 | 横向滑动显示已开放阵位、真实上阵船员、空位及下一锁定位；点击进入原阵容页面或显示解锁提示 |
| 场景 | 参考版天空、云朵、海浪、树叶及船只美术；轻量海浪循环与船只浮动，不引入新版 Spine 运行库 |
| 活动礼盒 | 点击进入现有“冒险”活动页，可继续访问 All Blue、转盘等活动 |
| 船只 | 点击进入本地船舱；默认梅丽号，进入船舱后按服务端返回的当前船体缓存对应外观，再回首页时显示。缓存按账号和区服区分，不作为船体购买或强化的依据 |
| 快捷栏 | 船员、装备、奥义、船舱、修行、常用六项；参考版宠物位置调整为本地已实现的船舱 |
| 修行展开栏 | 修行、潜能训练、船员养成、装备养成、奥义扩展、运宝；保留原修行等级条件 |
| 常用展开栏 | 背包、传书、图鉴、好友、聊天、设置；沿用现有入口的开放条件，切换账号仍从设置操作 |
| 底部主导航 | 换用参考版图标，保留原首页、阵容、远航、冒险、决斗、商店按钮位置、标签、通知及跳转逻辑 |

页面沿用原首页场景边界按比例排版，文字按区域宽度缩放，避免长昵称或较大货币数字换行覆盖下一栏。打开角色信息等全局弹窗时，首页按钮和阵容滑动暂停响应，避免穿透点击；常用和修行弹层可通过再次点击对应入口收起。

这是结合本地功能的布局与美术移植。参考版完整港口轮换、岛屿、其他玩家船只、宠物和任务系统未包含在本次修改中。

## 数据和代码

- `client/source/Game/Classes/MainPage.{h,cpp}`：首页布局、实时信息、阵容、快捷展开栏与原功能回调。
- `client/source/Game/Classes/MainFrame.{h,cpp}`：原主导航图标换肤，不替换全局弹窗和广播管理。
- `client/source/Game/Classes/ExpansionSystemsPage.cpp`：收到船舱快照后缓存该账号、该区服的船体外观。
- `resources/client/ported/home/v1/`：独立命名的首页 PNG 资源；两个船只图由参考骨骼资源的初始姿态合成。
- `scripts/import_home_ui.py`：维护用资源提取工具，需要已提取 APK 和 Pillow；常规克隆、部署、构建不需要执行。
- `resources/catalog/home-ui-v1.json`：资源版本 **1.82.0** 与图片校验信息。
- `deployment/server.py`、`deployment/catalog_update.py`：停止后再启动时发布首页资源及版本，保留现有规则和数据。

角色数据继续走原游戏连接和消息更新，首页不新增账号、奖励或战斗协议。实际点击继续发送原有新手引导按钮消息。旧 CCB 保留作为变量与回调兼容层；首页新资源缺失时记录日志并保留旧布局。

## 应用更新

1. 正常停止当前服务端，更新仓库后运行启动服务脚本，发布首页资源与版本。
2. 重新打包 Android 和 Web。主页布局包含 C++ 修改，仅更新图片不会替换旧客户端的布局。
3. Android 安装新包；Web 使用新构建产物刷新页面。

2026-11-04 已按后续授权完成 Android 与 Web 的编译、安装和实际操作验证，并修复验证中发现的问题。范围、截图及产物见[首页与养成界面安卓网页验证记录](首页与养成界面安卓网页验证记录.md)。
