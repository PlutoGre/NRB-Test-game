# 账号体系 Android 与 Web 实测记录（2026-11-03）

本次在 Windows 本机编译、部署，通过雷电模拟器和浏览器实际注册、登录、建角、完成新手流程及普通远航。Web 使用局域网地址，没有启动外网隧道。

## 环境与产物

- 仓库：`D:\test\NRB-Test-game`；部署、构建入口仍按仓库所在目录解析路径。
- 雷电设备：`emulator-5554`，Android 14 / API 34；测试包名为 `com.youai.dreamonepiece.platform.anzhi`。
- Web：本机 Chromium，通过 `http://192.168.30.101:18084/` 访问，使用原 Cocos 游戏画布。
- 通用 APK：`outputs/android/DreamOnePiece-debug.apk`；包含 armeabi、armeabi-v7a、x86。
- 模拟器包：`outputs/android/DreamOnePiece-emulator-x86-debug.apk`；仅包含 x86。
- 两种 APK 的最低及目标 SDK 均为 21。Web 完整产物位于 `outputs/web/`。

构建命令，在仓库根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File deployment/Build-Android.ps1 -Jobs 1 -SceneInspection
powershell -NoProfile -ExecutionPolicy Bypass -File deployment/Build-Web.ps1 -Jobs 1
powershell -NoProfile -ExecutionPolicy Bypass -File deployment/Start-Web.ps1 -SkipBuild
```

`-SceneInspection` 只用于本次调试包的只读场景观察，还需要设备本地标记才会启用；日常打包可省略。本机首次同时高并发构建时出现过链接器内存分配失败，改用 `-Jobs 1` 后构建成功。

## 已完成的真实验证

| 检查 | 结果 |
|---|---|
| 首次启动 | Android 和 Web 均先显示账号登录窗口；可以切换注册页面 |
| 注册 | 两端分别注册独立账号；确认密码不一致时拒绝提交 |
| 密码登录 | 已注册账号正确密码成功；错误密码显示“账号或密码错误” |
| 服务端输入校验 | 非法账号、确认密码不一致、重复注册均被拒绝；账号大小写归一后仍可登录 |
| 自动登录 | Android 关闭重开、Web 刷新后可恢复保存的凭证 |
| 账号切换与取消 | 切换时显示输入窗口；取消后再次点击进入仍要求认证 |
| 角色隔离 | A 账号创建 `NRBAC01`，B 账号创建 `NRBAC02`；服务器分别绑定角色 ID 4、5 |
| 新手流程 | 两个角色分别完成选船员、取名、新手战斗、招募及后续引导 |
| 跨端存档 | Android 创建的角色可用原账号密码在 Web 找回；原角色名、经验、货币和船员保留 |
| 普通远航 | Web 和 Android 均通过画布/触屏进入普通远航并获得胜利，正常显示船员经验和奖励 |
| 会话校验 | 恢复有效凭证成功；注销后的凭证再次恢复返回 401 |
| 服务端重启 | 完整停止并启动本实例后，两端已保存凭证仍能恢复；角色与已落库进度保留 |

Web 的一次普通远航使 `NRBAC01` 的经验从 `60/130` 变为 `70/130`，贝里从 `1000` 变为 `1114`。核对原有保存队列落库并重启服务端后，Android 实际登录仍显示上述数值。随后 Android 再次完成普通远航，正常获得奖励。

## 本次修复

1. **已有账号密码登录返回 503**：旧 Hibernate 对未指定类型的 `CHAR(32/64)` 查询结果使用 `Character`，读取盐和密码摘要时发生类型转换异常。`AccountService.java` 为账号和会话查询显式指定字符串/整数类型。修复后完成正确密码、错误密码、大小写账号、重复注册、恢复及注销回归。
2. **跨端低等级角色重新进入新手取名页**：原新手流程依赖客户端本地进度和本地引导包。服务端已确认新手完成时，新的客户端或缺少引导缓存的客户端仍可能重新进入取名流程。`InstructionManager.cpp` 按服务端完成状态恢复，并保存当前账号的本地完成标记；已经完成的新手无需再次读取旧引导包。
