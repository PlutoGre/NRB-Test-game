## 协议及保存验证

在正常账号认证和游戏登录后，通过实际 TCP 协议执行了 9 项初始检查：两活动免费机会独立、各自免费抽取及同编号重试、付费单次准确扣 30 钻石、钻石不足拒绝十连、积分不足拒绝兑换、旧进度版本拒绝、旧规则版本拒绝、拒绝操作不改变进度。

完成客户端游玩后，记录活动表、钱包、幂等回执、奖励传书、奥义、装备和背包，然后完整停止并启动当前部署实例。重启前后这些记录一致；两个账号重新登录读取的状态与数据库一致。再次发送最初的两次免费请求，服务端返回原操作的重放结果，没有新增传书、回执、抽取次数或扣费。两个角色重复领取已领的 10 次档位均被拒绝，资产不变。

初始化检查两活动及重试各作为一项，共 9 条原始结果；重启、账号隔离、重放和防重领另存结果。本次没有通过改系统时间、改数据库进度或固定随机种子制造达标状态。

## 本次修复

1. **活动 JSON 响应夹带缓冲区尾部字节**：MINA 池化缓冲区容量可能大于实际消息。活动响应限定有效长度，网络编码器按有效长度生成加密帧，避免 JSON 解析失败和等待。
2. **Web 加载新版活动 CCB 时中断**：旧 CCB 读取器不识别新版标签的 `shadowOffset`、`shadowOffset2`、`shadowOffset3`、`shadowOffset4`。仅兼容忽略这四个可选文字阴影字段，保留旧字体绘制及其他未知字段检查。
3. **中文缺字、文字过小和显示重叠**：新活动文字超出旧位图字库时，使用系统字体并保留节点布局；按字体配置计算字号，继承原可见状态，补齐转盘奖励图标及收集格显示。
4. **弹窗按钮位于裁剪区及触摸注册崩溃**：弹窗按屏幕坐标布局；菜单和滚动层在注册时设置触摸优先级，关闭、兑换和传书入口可正常点击。
5. **前往传书后无法正常返回**：通过主界面切页进入传书，继续使用原导航返回冒险。
6. **Web 产物资源版本记录过期**：构建清单从本次实际打包的 `version_web.cfg` 读取资源版本，记录为 1.79.0。

最终 APK 的 crash 日志为空，两端完成活动并保持运行；Web 控制台没有本次活动引发的异常或 CCB 断言。
