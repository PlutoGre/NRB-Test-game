在另一台 Windows 完整 clone 仓库，保留 `client`、`server`、`resources`、`scripts`、`deployment` 和文档的相对位置，按服务端文档操作。无需复制 `.debug` 中的旧机器路径、模拟器或临时调试产物。

日常双击项目根目录的 `启动服务.cmd` 或 `停止服务.cmd` 即可。首次启动自动部署，以后启动已有实例并保留数据。`deployment/server.cmd` 保留为手动部署入口；指定手机可访问地址的示例：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\deployment\Deploy-Server.ps1 -PublicHost 192.168.1.100
```

运行目录默认为本项目 `runtime/server`，Android 打包入口为 `deployment/build-android.cmd`，产物在 `outputs/android`。不需要修改固定盘符或工程路径。示例 IP 需要改为新电脑地址。已有数据迁移需先备份恢复，不能只复制源码。iOS 可通过 GitHub Actions 构建，真机安装仍需签名。

本次新增脚本尚未在新 Windows 实跑，也未执行客户端编译、构建或测试；前面调试环境的成功不代表新迁移流程已经验证。
