# 共享脚本

| 文件 | 用途 |
|---|---|
| `project_paths.py` | 按仓库根目录解析路径，供部署、Android 和 iOS 入口共用 |
| `configure_deployment.py` | 从 `resources/client` 生成 HTTP 资源、区服列表和客户端配置覆盖文件 |

通常通过 `deployment` 下的一键入口调用这些脚本。手动配置参考 [资源配置说明](../docs/reference/资源配置与已知问题说明.txt)。

`tools` 是本机下载的 SDK、NDK、Ant 等工具，不存放这里的项目脚本；`deployment` 存放面向使用者的部署、构建入口和运行管理程序。
